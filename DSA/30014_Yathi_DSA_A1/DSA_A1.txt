int a = 0, b = 0;
for(i=0; i<n; i++){
	a = a + rand();
}
for(j=0; j<m; j++){
	b = b + rand();
}

first loop runs from 0 to n-1 i.e n times
Second loop runs from 0 to m-1 i.e m times

Loops are sequential so adds up

Time complexity = O(n) + O(m) = O(n+m)

int a = 0, b = 0;
for(i=0; i<n; i++){
	for(j=0; j<n; j++){
		a = a + j;
	}
}
for(k=0; k<n; k++){
	b = b + k;
}

first loop - nested
	Both outer and inner loop runs n times so O(n^2)
Second loop runs n times so O(n)

Time complexity = O(n^2) + O(n) = O(n^2)
----------------------------------------------------------------

int a = 0;
for(i=0; i<n; i++){
	for(j=n; j>i; j--){
		a = a + i + j;
	}
}

nested loop.
	outer loop runs n times. = O(n)
	inner loop runs n-i times. sum of series = n(n+1)/2 = O(n^2)
	
Time complexity = O(n^2)
